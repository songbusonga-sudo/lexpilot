## 三分钟演示脚本

1. **0:00—0:25，真实需求**：东盟学生看得懂部分英文合同，却难以向中文服务人员说明押金纠纷。首页点击“东盟双语案例”。先说明材料全部为模拟内容。
2. **0:25—0:55，材料与背景**：展示英文合同、英文入住记录、中文退租聊天；进入“公共法律服务”，展示越南、自述事项发生于中国内地、中文加英文辅助核对。
3. **0:55—1:35，真实AI核对**：从概览或服务页发起核对，展示材料发送范围并勾选同意。页面显示真实等待秒数。说明模型返回后才做引用校验，不使用预设进度或伪造结果。
4. **1:35—2:10，证据核验**：展示中文问题及英文辅助翻译，点击“定位原文”；跨材料项目可打开另一份材料。把一项问题记录为争议，说明“单方主张”和“双方确认”的区别。
5. **2:10—2:40，带着材料求助**：下载咨询准备材料；展示报告AI附录，说明咨询材料不会自动发送给任何机构。官方链接用于自行查询，当前没有律师转介或法律援助受理接口。
6. **2:40—3:00，价值与边界**：展示手机端和另两类场景。说明目前完成中英辅助、中国内地事项整理；东盟各国实体法、更多语言和机构合作属于后续工作，不能宣称已经覆盖。

现场模型响应会有波动。提前打开一份完成核对的模拟事项供解释，保留另一份用于现场真实调用。失败时直接展示错误与重试，不能把截图或历史结果说成当次调用结果。

## 验证方法

```powershell
npm test
npm run build
# 以下将调用真实服务并产生API费用，只发送代码内的模拟材料
node --env-file-if-exists=.env tests/model-live.mjs
# 单独的测试数据目录，避免改动个人事项
$env:DATA_DIR='D:\projects\lexpilot\.work\competition-test-data'
$env:PORT='8267'
node --env-file-if-exists=.env server/index.js
# 另一个终端；默认测试地址为 http://127.0.0.1:8267
node tests/competition-browser.mjs
```

真实模型检查验证三个场景的核心问题、可用结果和原文引用。浏览器检查使用独立创建的模拟事项，结束后删除该事项，覆盖双语完整性、双材料引用、原文定位、争议保存、报告、咨询导出、背景变化后的失效、手机布局和图片识别结果不自动覆盖材料原文。

这些结果是少量模拟案例的功能联调，不是法律准确率、OCR准确率或真实用户效果评测。

2026年10月27日本轮最终运行：租房3项有效结果（17.1秒）、兼职3项（21.9秒）、实习3项（11.7秒）；东盟双语3项（17.2秒），包含两份材料对照引用。上述最终调用引用拒绝数均为0。合成图片中的2000元、800元及“维修凭证待提供”已识别，浏览器闭环与手机布局检查通过。数值仅反映这轮模拟输入，不代表其他材料的表现。
