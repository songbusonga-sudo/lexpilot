# 硅基流动接入说明

本地业务功能已经可以使用。以下两项需要外部 API：

| 功能 | 需要的模型能力 | 页面入口 |
| --- | --- | --- |
| 跨材料辅助核对 | 支持 Chat Completions 的文本对话模型，能稳定输出 JSON | 事项 → 事实核对 → 模型辅助核对 |
| 图片文字转录 | 支持图片输入的多模态模型，能识别中文合同或聊天截图 | 材料详情 → 图片文字识别 |

可以共用同一个硅基流动 API Key。若所选多模态模型也支持纯文本对话，可将两个模型变量设为同一模型 ID，实际效果需联调验证。

## 本机配置

在硅基流动控制台开通服务并准备可用余额，创建 API Key。复制控制台展示的完整文本模型 ID 和多模态模型 ID。

将项目根目录 `.env.example` 复制为 `.env`，在本机填写：

```dotenv
SILICONFLOW_API_KEY=你的API密钥
SILICONFLOW_TEXT_MODEL=控制台中的完整文本模型ID
SILICONFLOW_VISION_MODEL=控制台中的完整多模态模型ID
```

重启 `npm run dev`，刷新网页，在“服务设置”查看状态。

**不要把真实密钥写入前端文件或发到公开仓库。** `.env` 已加入忽略列表。无需在聊天中粘贴密钥，直接填写本机文件即可。

## 调用范围

- 后端固定调用 `https://api.siliconflow.cn/v1/chat/completions`。
- 上传材料不会自动请求模型。
- 辅助核对发送材料文字、文件名称、场景、阶段与已填写背景（含服务语言与事项发生地）；图片识别仅发送当前所选图片。核对对话框列出具体材料与字数。
- 每次外部调用均在页面显示发送范围并由用户确认。
- 图片识别限制10MB，文字分析单份最多16000字、总计最多80000字。超限明确拒绝，不会静默截取材料；扫描 PDF 尚未自动转图识别。
- 密钥不通过网页设置接口返回。

## 失败处理

未配置模型时显示“待配置”，本地功能照常工作。权限、余额或服务错误会显示状态码；超时可重试。模型返回格式不正确、输出被截断或双语字段缺失时不覆盖已有分析；不能在原文验证的单份或对照引用会被过滤。同一事项不并发重复分析。分析期间材料或背景变化时结果不保存，需按新内容重试。已保存结果在材料或背景变化后失效，不再进入当前核对清单、咨询导出或报告问题清单。

图片识别结果先进入编辑区，用户未保存前不会覆盖已有材料文字。公共法律服务页可选择中文加英文辅助，生成的问题保留原语言引用；英文为模型辅助翻译，需要人工核对。

## 当前验证范围

2026年10月27日使用配置的Qwen/Qwen3.5-35B-A3B完成租房、兼职、实习的真实调用、东盟中英双语跨材料核对和合成中文图片转录。记录分别在 `artifacts/model-live-results.json`、`artifacts/competition-bilingual-model.json`、`artifacts/competition-ocr-result.txt`。输入均为模拟材料，无真实用户文件。

真实浏览器检查覆盖双语结果、两份引用、原文定位、争议保存、报告与咨询材料导出、旧结果失效及手机布局。可通过 `node --env-file-if-exists=.env tests/model-live.mjs` 和 `node tests/competition-browser.mjs` 重跑，后者默认使用8267测试服务。重跑会产生实际API费用。

上述为小样本功能联调，不能当作模型法律准确率、翻译准确率或OCR识别率报告。当前版本不包含法律法规检索服务，也未接入律师转介或法律援助受理接口。
