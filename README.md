# 青盾 · 大学生权益工作台 v0.3

面向租房、兼职与实习的网页应用。首页按具体问题直接开始，无需注册；通过访客 Cookie 隔离个人事项、材料与报告。Vue 3、Vite、Express 与 Node 原生 SQLite。

## 启动

需要 Node.js 24。

```powershell
npm install
npm run dev
```

- 前端：<http://127.0.0.1:5267>
- 后端：<http://127.0.0.1:8266>
- SQLite：`data/qingdun.sqlite`，原始材料：`data/uploads/`，不占额外数据库端口。
- Vite 使用严格端口，端口被占用时不会自动切换。以上端口避开用户提供的本地项目端口清单。
- 生产预览：`npm run build` 后执行 `npm start`，访问后端地址。
- 根目录 `.env` 会在后端启动时读取；更改后需要重启后端。
- 前端支持自动更新；为避免Windows文件监听引起服务中断，后端修改后手动重启 `npm run dev`。

## 主要流程

1. 新建事项，选择租房、兼职或实习及实际阶段。
2. 上传合同、聊天、付款凭证和照片，核对文字、材料分类与事件日期。
3. 提取候选金额与日期，逐项标记材料记载、本人陈述、对方主张、双方确认或待核实。
4. 维护争议项目：对方主张、我的说明、涉及金额、核对状态、关联证据与缺失材料。
5. 租房照片按房间和入住/退租阶段分类、并排对照；在争议项目里关联照片与其他材料。
6. 押金实付、退款记录关联原始凭证；确认扣款由争议清单汇总，采用整数分计算。
7. 分别生成、编辑并保存协商说明、签约前提问清单和证据目录；导出 TXT 或结算 CSV。

材料或核对信息变化后，已有草稿显示重新核对提醒。事项支持修改、归档、恢复和永久删除；材料删除会清除对应事实与证据关联。所有演示材料均明确标记。

## 本轮新增

- 事项概览按实际材料缺口生成行动入口，可直接打开需要核对的材料。
- 三类模拟案例一键体验，支持确认后恢复初始案例。租房包含签约、入住、退租事件与两张明确标注的模拟示意图，图示不是真实房屋照片。
- 争议清单可展开关联材料与原文；材料修改后重新核对，删除后清理事件、台账和实习清单中的关联。
- 时间线合并材料与手动事件，支持新增、编辑、删除事件，并将日期未核实的记录排在后面。
- 兼职工时台账记录实际工时、此项约定报酬及已收金额，支持编辑和CSV导出。未知报酬不会默认为零或按广告最高金额计算；账面差额不等于确认欠款。
- 实习保障清单覆盖学校参与、保险、安全、报酬与退出，每项可保存状态、说明和关联材料。
- 事项报告包含背景事实、双方主张、时间线、场景核对、待办、证据目录及原文、已保存草稿。可下载独立HTML，在浏览器中打印或另存为PDF；报告不包含原始图片和附件。
- 在事项报告页导出完整JSON备份，包含原文件与SHA-256校验值。“我的事项”中恢复为独立副本，重建材料关联且不覆盖旧事项。备份最多100份材料、原文件合计80MB、单文件20MB；备份不加密，应妥善保管。
- 白底黑字灰色控件延续，新增表单、报告及清单适配手机；开发监听排除数据与输出目录。

2026年10月27日已用配置模型完成三类场景、双语跨材料核对与图片文字转录的真实联调，输入均为模拟材料。参赛官网核对、能力边界和三分钟演示脚本见 [参赛准备](./docs/AI法律大赛参赛准备.md)。

## 模型服务说明

接入方式见 [API接入说明](./docs/API接入说明.md)。没有 API Key 时，本地流程可以完整使用，不会模拟模型调用结果。

- 硅基流动文本模型：材料文字和实际背景的辅助核对，返回引用原文的待核实问题。
- 硅基流动多模态模型：图片可见文字转录，结果进入编辑区，人工确认后才保存。
- 密钥只从后端环境变量读取，不进入前端构建和设置接口。
- 调用前需在页面确认材料发送范围；上传本身不触发外部调用。
- 模型结果必须提供材料内逐字连续原文；不匹配的引用不显示为有效分析。

## 使用边界

- 默认监听本机，生产通过 HTTPS 反向代理公开访问，保留限速与来源校验。访客记录按 Cookie 身份隔离；尚无账号登录、跨设备同步或磁盘加密。清除 Cookie 后可能无法找回，重要材料应导出完整备份。
- 升级前的无归属数据保留但不对新访客开放，不会由第一个访客自动认领；迁移说明见 `docs/服务器部署.md`。
- 文本规则检查不代表完整法律审查。未检出问题不等于没有风险。
- 模型辅助、OCR及照片对照不确认材料真实性、损伤原因或最终责任；兼职、实习不能仅凭协议名称判断法律关系。
- 日期默认可能为上传时间，需要核实。双方确认是用户记录状态，不代表平台核验。
- 待核实和有争议扣款不进入确认扣款；账面余额不是最终应退金额的法律认定。
- 当前尚未接入法律法规检索或东盟各国法律数据库。文本模型、双语核对和图片转录已完成模拟材料的真实联调；法律准确性、翻译质量和真实学生试用仍需专业评审与更大样本验证。扫描 PDF 可先转为图片或手动补充文字。
